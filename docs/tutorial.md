# 대시보드 사용 안내

처음 데이터가 로드되면 **튜토리얼을 시작할까요?** 안내창을 표시합니다. 시작하지 않아도 바로 사용할 수 있고, 상단 **사용 안내**에서 다시 시작할 수 있습니다. 이전에 중단한 경우 이어서 보기와 처음부터를 제공합니다.

## 안내 순서

26개 화면을 5개 업무로 묶었습니다. 이전·다음 또는 업무 이름을 눌러 이동합니다.

1. **발주 살펴보기**: 매장·기준일, 부족·폐기·과잉, 검색·필터, 품목별 추천 근거, 재고 추이와 우선 품목
2. **설정과 요청**: 성향, 수치 기준과 수요·지연 시나리오, 한도·제외 품목, 설정 가져오기·내보내기, 이번 요청, 최종 적용 기준
3. **행사와 발주서**: 후보 비교, 행사·특이사항 입력, 수요 반응과 BOM 미리보기, 조건 적용·해제, 수동 수량 조정, CSV 초안 검토
4. **재고 마감**: 실제 기록·필터·내보내기, 묶음별 사용기한, 다음 날 입력·추적, 마감 확인·저장, 수정·다음 기록·백업
5. **이력과 기준**: 이력 기간·필터·검색·페이지, 예정·실제 입고 상세, 조회 결과 내보내기, 데이터 사용과 계산 가정

예시 버튼으로 부족 품목 필터링, 요청 해석, 행사 수요 +30%, 패티 한 박스 추가, 다음 날 마감 기록을 직접 확인할 수 있습니다. 자동 예시는 규칙 해석을 사용하며 외부 LLM 호출을 만들지 않습니다. 사용자가 자유 문장 해석을 켜고 직접 요청하면 기존 서비스와 같은 API를 사용합니다.

## 연습값과 기존 기록

튜토리얼을 시작하면 현재 화면 상태를 보관한 뒤 매장 A·2026-09-30·기본 설정으로 연습합니다. 설정·행사·재고의 실제 저장 함수는 `WorkspaceStorage`를 통해 실행하며, 연습 중에는 메모리에만 씁니다. 저장된 원래 값은 덮어쓰지 않습니다. 종료 또는 새로고침으로 연습값이 사라집니다. 종료할 때는 원래 선택한 매장·날짜·탭·필터·수동 수량·설정·요청을 복원합니다. 진행 위치만 별도 키 `fresh-order-tutorial-v1`에 보관합니다.

CSV·JSON 다운로드는 사용자가 누를 때만 실행합니다. 다운로드한 연습 파일은 일반 파일처럼 남습니다. 실제 공급사 주문은 기존과 같이 전송하지 않습니다. 원본 데이터, 엔진 계산, API 경로와 기존 저장 키는 바꾸지 않습니다.

## 표시와 접근성

- 실제 영역 주위의 노란 테두리, 주변 밝기 조정과 해당 화면의 짧은 설명
- 안내창에 단계 번호와 현재 위치 경로 표시 (예: 발주 신청 › 설정 › 한도·제외 품목). 페이지·설정 탭·상세 창이 바뀐 단계에는 어디서 어디로 이동했는지 한 줄 추가
- 화면 전환 순서: 설명창이 사라짐 → 이동할 상단 메뉴·설정 버튼·탭 표시와 '이제 ○○으로 이동합니다' 안내 → 화면 변경 → 목표까지 부드러운 스크롤 → 강조 테두리 → 설명창. 설정 창과 상세 창 안에서는 그 창만 스크롤
- 가까운 영역은 강조 테두리가 이어서 움직이고, 다른 화면이나 먼 영역은 기존 강조를 지운 뒤 새로 표시
- 전환 중에는 다음·이전 버튼과 화면 클릭을 막아 연속으로 눌러도 한 단계만 이동
- 전체 진행 표시와 업무별 바로 이동, 상단의 연습 표시, 언제든 종료
- 설정·데이터 기준의 모달 안에서도 안내창을 같은 영역에 배치
- 작은 화면에서는 하단 안내창과 스크롤되는 입력 영역 사용
- 키보드 접근, 안내 제목에 초점, Escape 종료, 모션 감소 설정 반영 (애니메이션 없이 바로 이동하고 위치 경로·이동 문구는 유지)
